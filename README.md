# หน้าเว็บ — ลงทะเบียนนักกีฬา สีเขียว

หน้าเว็บนี้เป็นไฟล์เดียว (`index.html`) วางบน GitHub Pages และดึง/บันทึกข้อมูลผ่าน Google Apps Script

## หน้าต่าง ๆ
| เมนู | ใช้ทำอะไร |
|---|---|
| ภาพรวม | ตัวเลขสรุป, เลือกกีฬา 5 ชนิด, นัดแข่งถัดไป |
| วอลเลย์บอล / เซปักตะกร้อ / เปตอง / เทเบิลเทนนิส / แบดมินตัน | **ทีม & ลงทะเบียน**: ตั้งทีม, ลงชื่อเข้าทีมเป็นตัวจริงหรือตัวสำรอง · **ปฏิทินแข่งขัน** ของกีฬานั้น |
| ปฏิทิน | ปฏิทินรายเดือนของทุกกีฬา (แยกสีตามกีฬา) กดที่วันเพื่อดูนัดแข่ง สลับเป็นมุมมองรายการได้ |
| นักกีฬา | รายชื่อบุคลากรทุกคน ดูว่าแต่ละคนอยู่ทีมไหนบ้าง ค้นหาชื่อและกรองตามฝ่ายได้ |
| สรุป | ตารางสรุป พิมพ์ได้ ดาวน์โหลด CSV ได้ |

- ข้อมูลนักกีฬา: ชื่อ · นามสกุล · ชื่อเล่น · ฝ่าย · ประเภทนักกีฬา (ตัวจริง / ตัวสำรอง)
- 1 คนลงได้หลายกีฬาและหลายทีม ถ้าเคยลงทะเบียนแล้ว เลือกชื่อเดิมในช่อง "เคยลงทะเบียนแล้ว?" ระบบจะกรอกข้อมูลให้
- โหมดผู้ดูแล (ลิงก์ท้ายหน้า + รหัส): เพิ่ม/แก้นัดแข่ง บันทึกผล ตั้งผู้ประสานงาน ลบทีม/รายชื่อ

## ติดตั้ง
1. ติดตั้งฝั่ง `apps-script` ให้เสร็จ แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
2. เปิด `index.html` แก้บรรทัด `const API_URL = '...';` ให้เป็น URL นั้น (บันทึกแบบ UTF-8)
3. สร้าง repository แบบ Public บน GitHub แล้วอัปโหลด `index.html` กับ `README.md`
4. **Settings → Pages → Deploy from a branch → main / (root) → Save**
5. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

## ปรับแต่ง
- สีประจำกีฬาและไอคอน: ค้นหา `const UI = {` ใน `index.html`
- สีหลักของเว็บ: ตัวแปร `--g` (เขียวเข้ม) และ `--lime` ในส่วน `:root`
