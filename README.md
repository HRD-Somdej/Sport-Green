# หน้าเว็บ — ทีมสีเขียว กีฬาสีปีใหม่ 2570 · v7

```
github/
├── index.html      ← หน้าเว็บทั้งหมด (ภาพโรงพยาบาลฝังอยู่ในไฟล์นี้แล้ว ไม่ต้องมีโฟลเดอร์รูป)
└── README.md
```

## ติดตั้ง
1. เปิด `index.html` แก้บรรทัด `const API_URL = '...';` เป็น URL `/exec` ของ Apps Script (บันทึกแบบ UTF-8)
2. อัปโหลด `index.html` ขึ้น repository บน GitHub (ไฟล์เดียวพอ)
3. **Settings → Pages → Deploy from a branch → main / (root) → Save**

## หน้าในเว็บ
| เมนู | ใช้ทำอะไร |

| หน้าแรก | ภาพโรงพยาบาล · ตัวเลขสรุป · เลือกชนิดกีฬา · นัดถัดไป · กองเชียร์ · ปุ่มคณะทำงานสี |
| ชนิดกีฬา ▾ | 5 กีฬา: ตั้งทีม/ลงชื่อ (ตัวจริง · สำรอง · ไม่ระบุ) + ปฏิทินของกีฬานั้น |

| ปฏิทินแข่งขัน | รายเดือน/รายการ · วันเดียวมีหลายรายการ · มีทั้งนัดแข่งและกิจกรรม |

| สรุป | สรุปทุกกีฬา กองเชียร์ คณะทำงาน · CSV · พิมพ์ |

## ผู้ดูแล (ปุ่มกุญแจมุมขวาบน · รหัส 1234)
- ตั้งประเภทการแข่งขัน · ผู้ประสานงาน
- ปฏิทิน: กด **+** ในช่องวัน หรือ "เพิ่มรายการในวันนี้" → **บันทึกแล้วเพิ่มต่อ** เพื่อเพิ่มหลายรายการในวันเดียว · "คัดลอกเป็นรายการใหม่"
- แก้ไข/ลบรายชื่อ (ไอคอนดินสอ) · เปลี่ยนไซซ์เสื้อในตาราง · เพิ่ม/แก้คณะทำงานสี
- เข้าสู่ระบบค้างไว้จนปิดแท็บ

## ความเร็ว
- จำข้อมูลล่าสุดไว้ในเครื่อง → เปิดเว็บครั้งถัดไปแสดงผลทันที แล้วค่อยอัปเดต
- อัปเดตอัตโนมัติทุก 1 นาที เฉพาะเมื่อข้อมูลเปลี่ยน (หน้าไม่กระตุก ตำแหน่งที่เลื่อนไว้ไม่หาย)

## เปลี่ยนรูป
ใส่ลิงก์รูปใหม่ที่ `ASSETS.hero` ด้านบนของ `index.html` (ว่างไว้ = ใช้ภาพโรงพยาบาลที่ฝังไว้)
ถ้ารูปใหม่โหลดไม่ได้ ระบบจะกลับไปใช้ภาพที่ฝังไว้ให้อัตโนมัติ
(ใส่รูปประจำกีฬาได้ที่ `sports: { volleyball: 'assets/volleyball.webp' }`)
